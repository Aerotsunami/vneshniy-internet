# Внешний интернет

PWA-архив зарубежных инфоповодов для русскоязычного Telegram-канала. Приложение работает как статический сайт, устанавливается на телефон и сохраняет уже открытые выпуски для чтения без сети.

## Как устроен архив

Каждый выпуск хранится отдельным файлом:

```text
content/issues/YYYY-MM-DD.json
```

Во время сборки скрипт проверяет структуру, даты, ссылки, число материалов и ограничение на AI-темы, а затем создает единый `public/archive.json`. История изменений остается в Git, поэтому любой выпуск можно восстановить или исправить через pull request.

## Локальный запуск

```bash
npm install
npm run dev
```

Проверка перед публикацией:

```bash
npm run check
```

## Новый выпуск

1. Скопировать последний JSON-файл в `content/issues/`.
2. Переименовать его в дату нового выпуска.
3. Обновить материалы и источники.
4. Запустить `npm run content:check`.
5. Создать pull request.

Подробности: [архитектура](docs/ARCHITECTURE.md) и [контракт автоматизации](docs/AUTOMATION.md).
